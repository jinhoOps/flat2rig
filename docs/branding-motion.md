# flat2rig 브랜딩·로고 모션

## 구성

- 위치: 앱 헤더의 정적 로고와 시작 화면의 작은 로고 루프. 별도 `/brand.html`에서 같은 컴포넌트를 검토한다.
- 중심 형태: 기존 로고의 고정 원화판, 코발트 리깅판, 피벗을 유지한다. 임의의 AI 심볼이나 캐릭터를 추가하지 않는다.
- 재질과 색: `DESIGN.md`의 Daylight Acrylic, Graphite `#161920`, Studio Cobalt `#2456D6`, 무채색 종이. 색상 오라와 글로우는 사용하지 않는다.
- 워드마크: 소문자 `flat2rig`, `2`에 코발트. 헤더의 추가 STUDIO 배지는 제거해 이름 자체를 읽게 한다.
- 로고: 앱 타일용 `public/logo.svg`, 투명 바탕 심볼 `public/brand/mark.svg`, 반전 심볼, 재사용 가능한 React 컴포넌트. 창 아이콘도 앱 타일과 일치시킨다.

## 루프

10.8초, 커서 없음. 처음부터 두 레이어가 보이고, 모든 도형은 같은 요소를 유지한다.

1. 정렬된 원화판과 리깅판.
2. 리깅판이 옆으로 분리되고 메쉬가 나타난다.
3. 고정 피벗을 중심으로 작은 각도 변형. 이 상태를 포스터로 사용한다.
4. 피벗으로 복귀하고 메쉬가 사라진 뒤 두 판이 다시 정렬된다.

역재생되는 작업 데이터는 없다. 로고 자체의 정렬/변형 운동이며, 얼굴 자동 검출이 이미 구현됐다는 제품 시연으로 표시하지 않는다. 사용자가 파일을 열면 루프는 언마운트된다. 화면 밖과 숨겨진 탭에서는 정지하고, 모션 축소 설정에서는 포스터를 표시한다. 사용자가 정지/재생을 선택할 수 있다.

## Stageshow 적용

`tilted-stack` gold를 출발점으로 같은 셀에 놓인 레이어, 절제된 각도, 전경/배경의 위계를 가져온다. 영수증 문구와 창 형태는 제거하고 제품의 기존 레이어 심볼로 바꾼다. 작은 로고 모션이므로 가짜 앱 창이나 UI 문구를 덧붙이지 않는다.

화면 크기는 400×220, compact는 358×200. 실제 시작 화면에서는 358px 슬롯을 사용한다. 같은 모션을 390px 검토 페이지와 데스크톱 호스트에서 촬영하고, 전체 루프/상태별/모션 축소 검사를 수행한다. 결과는 컴포넌트 옆 `REHEARSAL.md`에 기록한다.
